# Правовое соответствие: 161-ФЗ, ОД-2506, отличие от 115-ФЗ

## Как решение соблюдает закон

1. **Обязательные признаки не отменяются моделью.** Срабатывание любого из R01–R12 →
   законная приостановка перевода на 2 дня (для СБП/карт — отказ с правом повторить).
   ML-скоринг применяется только к операциям, где ни один признак не сработал
   (см. `src/decision.py`).
2. **Подтверждение клиента исполняет операцию**, кроме R01: при получателе в базе ЦБ
   период охлаждения обязателен даже при согласии (для повторной операции по карте/СБП —
   до конца следующего календарного дня, выходные не продлевают).
3. **Клиент в базе ЦБ:** банк может приостановить карту/ДБО (при сведениях от МВД —
   обязательно); если не приостановил — переводы физлицам ≤ 100 тыс. ₽/мес
   (больше — через отделение; на юрлиц лимит не распространяется).
4. **Признак мошеннической выдачи наличных:** лимит снятия в банкомате 50 тыс. ₽/сутки
   на 48 часов, свыше — в отделении.
5. **Уведомление клиента** — как подтвердить или повторить операцию (шаблоны в
   `src/explain.py`).

## Отличие от 115-ФЗ

Меры по 115-ФЗ (противодействие отмыванию) — **отдельный процесс** с другими основаниями
и порядком восстановления доступа. Решение их не смешивает: R01–R12 и 161-ФЗ — про
мошенничество против клиента (ОБДС), 115-ФЗ — про легализацию. Блокировки по 115-ФЗ
не входят в контур этого решения.
